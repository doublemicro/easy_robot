# Stick Fight — 1:1 졸라맨 대전 환경

강화학습 AI를 위한 2D 대전 게임 환경. 게임 로직(헤드리스)과 화면(pygame)이 분리되어 있어서,
학습할 때는 로직만 빠르게 돌리고 사람이 플레이할 때만 화면을 켠다.

## 웹에서 하기 / 배포 (v16)

- 브라우저 버전: `web/` 폴더 (pygbag으로 만든 정적 사이트). Vercel이 이 폴더를 그대로 올린다 (`vercel.json`)
- 로컬에서 확인: `python -m http.server -d web 8000` → http://localhost:8000 (처음 로딩에 파이썬 런타임을 받아 와서 몇 초 걸림)
- 게임을 고친 뒤 웹 버전 다시 만들기: `pip install pygbag` → `python -m tools.build_web` → `web/`를 커밋하면 Vercel이 다시 배포
- 게임 글자를 바꿨으면 먼저 `pip install fonttools` → `python -m tools.subset_fonts` (한글 폰트를 쓰는 글자만 남김)

## 설치와 실행

```bash
pip install pygame-ce numpy
python play.py                      # 메뉴 (마우스 클릭 또는 ↑/↓ + Enter)
python play.py --start training     # 바로 훈련장
python play.py --start match        # 바로 봇 대전 (P2 = 공격형 봇)
python play.py --start match --p2 human   # 2인 플레이
python -m tests.test_rules    # 규칙 테스트 + 시뮬레이션 속도 측정
python tools/pose_sheet.py    # 행동별 모션을 한 장의 이미지로 (pose_sheet.png)
python tools/startup_strip.py # 공격 시작 후 0~17프레임 화면 (startup_strip.png)
```

## v11: 숙이기 + 하단 경직 (2026-10-18)

사람 테스트에서 나온 문제: 리그 AI가 찾은 가장 좋은 방법이 **원거리 → 대쉬 공격 → 콤보**.
원거리를 피하려면 하단 공격으로 숙이는 수밖에 없었는데, 하단 후딜(24) 중에 대쉬 공격이 들어와 할 게 없었다.
또 하단은 맞혀도 -5라 콤보가 안 이어지고 상대가 바로 정면으로 반격했다.

- **숙이기** (`Act.CROUCH = 12`, `St.CROUCH`, 라벨 `CROUCH`): 누르고 있는 동안 낮은 자세 (판정 높이 72 = 하단 공격 자세와 같음)
  - 피함: 상단, 투사체 / 맞음: 하단, 정면, 대쉬 공격 (대쉬 공격은 점프·패링으로)
  - 숙인 채로는 못 걷는다. 떼면 바로 일어서고, 숙인 채 공격·점프·대쉬·패링을 누르면 그 행동이 바로 나간다 (후딜 없음)
  - 조작: P1 **S**, P2 **↓**. 모션은 `poses.py`의 `crouch` (깊이 웅크리고 뒷무릎을 바닥 가까이, 두 주먹 얼굴 앞 가드)
- **하단**: 후딜 24는 그대로, 경직 22 → 30, 넉백 2.0 → 0.5
  - 맞히면 -5 → **+3**. 정면 캔슬이 이어지는 거리 70 → **85px** (사거리 끝 86~94px에서는 여전히 안 이어짐), 상단 캔슬은 70px 이하
  - 부작용: 넉백이 벽꽝 기준(1.5)보다 작아져 **하단으로는 벽꽝이 안 난다** (정면·상단·강공격 등은 그대로)
- AI: 행동 12 → 13, 관측 80 → 82 → **기존 체크포인트(runs/stage1, runs/league)는 못 쓴다. 다시 학습 필요**

- 밸런스 기록: `python -m tools.report_exploit "RANGED > DASH > DASH_ATK > MID" --note "..."` 로 사람이 본 패턴을 비율 없이 기록.

## v10: AI 학습 — 1단계 PPO (2026-10-18)

게임 규칙·화면(game/)은 그대로. 추가된 것:

```bash
pip install torch                     # (이미 있으면 생략)
python train.py                       # 학습 (또는 train.bat). 기본 1천만 판단, 이 PC 약 7분
python train.py --steps 2000000 --name test        # 짧게
python train.py --resume runs/stage1/latest.pt     # 이어서
python -m tools.eval_ai runs/stage1/latest.pt --n 200 [--greedy]   # 봇 상대 승률
python play.py --start match --p2 ai [--ai runs/stage1/latest.pt]  # 학습된 AI와 대전
python -m tests.test_ppo
```

- `ai/policy.py`: 작은 MLP (관측 80 → 256 → 256 → 행동 12개 / 가치 1개, 정책·가치 몸통 따로) + 체크포인트를 봇처럼 쓰는 `PolicyBot` (`relative_actions = True`, obs만 봄, 반응 시간 130~240ms)
- `train.py`: PPO 직접 구현 (GAE λ=0.95, γ=0.99, clip 0.2, 4 epoch, 미니배치 4096, 엔트로피 0.01, lr 2.5e-4).
  작업 프로세스(코어 수 - 1)마다 8판씩 동시에 돌리고 반복당 약 2.2만 판단. 판마다 내 자리(P1/P2)는 무작위
- 커리큘럼 (최근 300판 승률): 하위 100% → (하위 80%↑) 중간 80%+하위 20% → (중간 75%↑) 상위 70%+중간 20%+하위 10% → (상위 50%↑ 기록)
- 저장: `runs/<name>/latest.pt`, `clear_<봇>.pt`(단계 통과 순간), `best_<봇>.pt`(그 봇 상대 최고 승률), `log.csv`
- `play.py`의 `BotController`는 `relative_actions`가 있는 봇이면 env와 같은 방식으로 좌우를 바꿔 넣는다. 메뉴의 AI 대전 버튼은 아직 비활성 (4단계)

### 결과 / 발견
- 학습이 매우 빠름: 첫 시험(100만 판단, 1분)에서 이미 하위·중간·상위 모두 100% (KO, 평균 약 8초)
- 본 학습(1천만 판단, 6.5분): 단계 통과 하위 16만 / 중간 27만 / 상위 38만 판단. 최종 `latest.pt`는 eval_ai 200판 기준
  하위·중간·상위 모두 승 100% (확률/greedy 둘 다), 평균 체력차 +85~+94, 전부 KO
- 쓰는 기술: 하단·정면 연타 + 앞 대쉬로 붙기가 대부분. **상위 봇이 끊임없이 붙어서 때리는 상대에 약하다** —
  "110px 밖이면 대쉬/전진, 안이면 하단·정면 무작위" 스크립트만으로 하위 96% / 중간 76% / 상위 55% 이김
- → 2단계(GRU) 전에 상위 봇을 러시 대응형으로 보강하거나, 3단계 셀프플레이를 앞당기는 게 의미 있음

### 사람 테스트에서 찾은 문제 → 대응 (v10)
- 문제: 거리를 벌려 AI의 대쉬 공격을 헛치게 한 뒤 바로 대쉬 공격으로 반격하면 AI가 그냥 진다.
  원인: 상위 봇은 대쉬 공격을 항상 "위협"으로 봐서 헛쳐도 벌하지 않았고, 다른 봇도 안 벌함 → AI는 대쉬 공격이 공짜라고 배움
- `SpacerBot` ("spacer", 거리 조절 봇): 사거리 바로 밖에서 기다리다 헛친 공격을 대쉬 공격·정면·하단으로 벌함 (사람 방법 재현).
  1단계 AI 상대 30% 승 (상위 봇은 0%), AI 대쉬 공격의 34%가 헛치고 반격당함
- 상위 봇: 헛친 대쉬 공격도 판정이 끝나면 벌하도록 고침
- `train.py` 단계 4 (리그): 과거의 나 40% + 거리 조절 25% + 상위 25% + 중간 10%. `--resume ... --stage 4`로 이어서

| 3 | 44~59 | 강공격 | 22 | 가장 밝은 빛 + 깜빡임 |
| 자동 | 60 (1초) | 무조건 3단계로 나감 | 22 | |

단계가 바뀌는 순간과 손을 떼는 순간 3프레임 번쩍인다. 손을 떼면 10프레임 동안 팔을 끝까지 들어올렸다가 내려찍는다.
그래서 가장 빠른 강공격도 차지 시작부터 24프레임이 걸리고, 반응이 가장 느린 상대(240ms)도 보고 정면 공격으로 끊을 수 있다.

**상성**: 하단 → 점프로 회피 → 상단이 점프를 잡음 → 하단 자세가 상단을 피함. 패링은 일반 근접/투사체를 받아치지만 읽히면 손해.

**패링 vs 강공격**: 패링을 남발하면 강공격(주황빛 예비동작)에 깨진다. 강공격은 기를 모으는 동안 무방비라
정면 공격으로 끊거나 점프/대쉬로 피할 수 있다. 기를 모으다 떼는 페인트로 상대 패링을 헛치게 만들 수도 있다.

**콤보**: 공격이 맞으면 10프레임 안에 *다른 종류*의 공격으로 캔슬할 수 있다 (최대 4타).
예: 정면 → 하단 → 상단. 강공격은 콤보에 넣을 수 없다. 콤보가 길어질수록 데미지가 줄어든다 (타당 12%, 최소 40%).
입력은 6프레임 선입력이 된다.

## 학습 환경 사용법

```python
from ai import StickFightEnv
from ai.bots import AggroBot

env = StickFightEnv(opponent=AggroBot())
obs, info = env.reset(seed=0)          # obs: float32 벡터 (69차원)
obs, reward, done, _, info = env.step(action)   # action: 0~11 (11 = 강공격 버튼 누르고 있기)
```

- 보상: 승리 +1 / 패배 -1, 그리고 `shaping × (준 데미지 − 받은 데미지) / 100`
- 상대는 `act(obs, world, me)`를 가진 객체면 무엇이든 된다 → 학습된 신경망도 같은 형태로 감싸면 self-play
- 관측은 항상 "상대가 오른쪽"이 되도록 좌우를 뒤집어서 준다
- 두 플레이어 모두 각자의 Perception으로 상대를 본다. 룰 기반 봇에게도 지연된 세계(SeenWorld)를 넘긴다
- AI 모델(신경망 구조, 학습 방법)은 아직 정하지 않았다. 여기 있는 건 모델이 받을 입력의 규칙까지다
